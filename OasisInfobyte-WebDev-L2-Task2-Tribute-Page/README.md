# 🇮🇳 Dr. A. P. J. Abdul Kalam — Tribute Page

A visually engaging and responsive tribute website dedicated to **Dr. A. P. J. Abdul Kalam**, India's renowned scientist, former President, and the beloved "Missile Man of India."

This project was developed as part of the **Oasis Infobyte Web Development & Designing Internship – Level 2, Task 2**.

## ✨ Features

* 🎨 Clean, modern, and professional design.
* 🖼️ Prominent portrait of Dr. A. P. J. Abdul Kalam.
* 📖 Biography section covering his life and contributions.
* 🏆 Timeline highlighting important milestones and achievements.
* 💬 Inspirational quote section.
* 🎨 Elegant navy blue, cream, white, and golden color palette.
* 🔤 Beautiful typography using Playfair Display and DM Sans.
* 📱 Responsive layout for desktop, tablet, and mobile devices.
* 🔗 Navigation links for easy access to different sections.
* 📚 Research sources included for further reading.

## 📖 Website Sections

### 1. Hero Section

Introduces Dr. A. P. J. Abdul Kalam with his name, an inspirational tagline, and a prominent portrait.

### 2. Biography

Presents his early life, education, scientific career, contributions to India's technological development, and presidency.

### 3. Key Achievements

A timeline highlighting important events and milestones from his life.

### 4. Inspirational Quote

Features a memorable quote associated with Dr. Kalam, presented in a distinct visual section.

### 5. Legacy Section

Celebrates his dedication to education, scientific progress, and inspiring young minds.

### 6. Footer

Includes project information and links to research sources.

## ⚙️ How to Run Locally

Follow these simple steps to run the project on your computer.

**Step 1:** Download or clone the project repository.

**Step 2:** Open the `Tribute-Page` folder in Visual Studio Code.

**Step 3:** Make sure the image is saved inside the `images` folder.

**Step 4:** Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code for a convenient development experience.

**No additional dependencies or installation are required.**
