# 🧮 Calculator Website | Oasis Infobyte WebDev Level 2

A modern, responsive, and fully functional Calculator Website built using **HTML5, CSS3, and JavaScript** as part of the Oasis Infobyte Web Development & Designing Internship – Level 2, Task 1.

The calculator provides a clean and user-friendly interface for performing basic arithmetic operations with interactive functionality and keyboard support.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Modulus operation
- 🔢 Decimal number calculations
- ⌫ Delete the last entered character
- 🧹 Clear (C) functionality
- ⚠️ Division-by-zero error handling
- ⌨️ Keyboard input support
- 🔄 Multiple calculations using operator chaining
- 🎨 Clean and modern user interface
- 📱 Responsive design for desktop, tablet, and mobile devices
- ⚡ Interactive calculations powered by JavaScript

## ⚙️ How to Run Locally

Follow these steps to run the calculator on your computer.

### 1. Clone the Repository

Open your terminal and execute:

```bash
git clone https://github.com/Jitendra-razz05/OasisInfobyte-Tasks-WebDev.git
```

### 2. Open the Project Folder

```bash
cd OasisInfobyte-Tasks-WebDev/OasisInfobyte-WebDev-L2-Task1-Calculator
```

### 3. Run the Project

Open the `index.html` file in your web browser.

Alternatively, open the project folder in Visual Studio Code and run it using the Live Server extension.

**No additional dependencies or installation are required.**
