# To-Do Web App

A simple and responsive To-Do Web Application built using **HTML5, CSS3, and Vanilla JavaScript**. It helps users manage daily tasks by adding, editing, completing, and deleting tasks.

## 📌 Project Overview

This project was developed as part of the **Oasis Infobyte Web Development and Designing Internship — Level 2, Task 3**.

The application provides separate sections for pending and completed tasks, making it easy to track daily activities.

## ✨ Features

- **Add Tasks:** Add new tasks using the input field.
- **Pending Tasks:** View all tasks that are not yet completed.
- **Mark as Complete:** Mark a pending task as completed.
- **Edit Tasks:** Update task descriptions using inline editing.
- **Delete Tasks:** Delete tasks from either list.
- **Task Counters:** View the number of pending and completed tasks.
- **Timestamps:** Display when a task was added and completed.
- **Local Storage:** Save tasks in the browser so they remain available after refreshing the page.
- **Empty State Messages:** Display helpful messages when task lists are empty.
- **Responsive Design:** Works on desktop, tablet, and mobile screens.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in your web browser.
5. Enter a task and click **Add Task** to get started.

You can also use the **Live Server** extension in VS Code to run the application.

## 📖 How to Use

1. Enter a task in the input field.
2. Click **Add Task** to add it to the Pending Tasks section.
3. Click **Complete** to move a task to the Completed Tasks section.
4. Click **Edit** to modify a task.
5. Click **Delete** to remove a task.
6. Check the counters to track pending and completed tasks.

Tasks are stored in the browser's Local Storage, so they remain available after a page refresh in the same browser.
